# .brain/modes/consolidate.md - DREAM CYCLE (MEMORY CONSOLIDATION PROTOCOL)

*MODE CONTRACT: living document; Gate 6 may refine it under double veto, but human confirmation for Operator Profile updates and the double veto on skill promotions may never be weakened.*

## ENTRY CRITERIA
Operator-triggered ("consolidate", "run the dream cycle", "maintenance pass"), or recommended by the agent after each harvest or roughly every 10 pipeline runs — recommended, never self-started. This mode touches only the brain's memory layer (ledger, scoreboard, skills, Boot Digest verification); product source is never modified.

## THE PRIME LAW
Consolidation looks for MEANING ACROSS entries, not length within them. Where the metabolism laws compress by size, the Dream Cycle connects: patterns spanning multiple lessons, contradictions between entries, preferences hiding inside repeated corrections, and knowledge gone stale.

## MANDATORY SEQUENCE
1. **Full memory read:** the entire ledger (all sections), the scoreboard tallies, every skill file, and the Operator Profile.
2. **Cluster and merge:** ledger entries sharing a root cause merge per Governance Laws 3 and 7; contradictions between entries are flagged to the operator, never silently resolved.
3. **Promote patterns:** defect classes recurring across scoreboard runs, and lessons appearing across 2+ ledger entries, are drafted into the relevant skill file — passing the standard Gate 6 double veto (Architect structural audit + Security sign-off) before any disk write.
4. **Expire and re-verify:** entries past the 6-month verification window (Ledger Law 9) are re-verified now where the environment permits, or marked STALE-REVERIFY-BEFORE-USE.
5. **Profile proposals:** corrections forming a repeated pattern (3+ occurrences) are drafted as CONTEXT-BOUND profile entries and PRESENTED to the operator with the pattern evidence — written only on explicit confirmation. Profile entries repeatedly overridden since the last cycle are challenged: confirm or delete. The operator's live word remains supreme at all times (Profile Charter, Ledger Law 8).
6. **Documentation verification:** confirm the Boot Digest AND the Operator's Guidebook (`PROMPT_GUIDE.md`) still match current governance — mode and skill counts, section lists, version stamp, feature claims. Digest drift is reported to the operator (digest edits remain human-approved); guidebook drift may be corrected within the run and disclosed in the report.

## EXIT ARTIFACT
The Consolidation Report: what was merged, promoted, expired, and challenged, plus every profile proposal awaiting the operator's yes/no. Recorded as a `consolidate` notation line on the scoreboard, excluded from the run tallies.
