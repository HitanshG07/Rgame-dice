## Root causes

1. **No overlay body scrolls.** `UITheme.overlay` returned a plain `Frame`, so any
   content taller than the panel was unreachable. This is the shop bug.
2. **The V7 panels have no data path.** `V7ForgePanel` exposes only
   `show`/`hide`/`onCommitClicked`; there is no method by which dice state could
   ever reach it. `V7MenuPanel` exposes only `openOverlay`/`closeAll`.
3. **`onCommitClicked` is never connected** in ClientBootstrap, so even a fully
   built forge could not submit.
4. **StateSync feeds exactly one thing:** `hudCtrl:updateBalances(cash, gems,
   diamonds)`. Nothing else in the client receives server state.

## Conclusion

The operator's description was accurate: "no ui element is properly working its
all broken down only the dice rolls." The V7 UI is a complete visual design with
a working roll path and no other data connection.
